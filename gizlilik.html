Gizlilik Politikası

Bu web sitesi, Lütfü Koca tarafından kişisel portfolyo ve bilgilendirme amacıyla hazırlanmıştır.

1. Kişisel Verilerin Toplanması

Bu web sitesinde kullanıcı kaydı, giriş sistemi, iletişim formu veya kişisel veri toplama amacı taşıyan bir uygulama bulunmamaktadır.

2. Çerezler ve Takip Teknolojileri

Bu web sitesinde tarafımızca eklenmiş reklam çerezleri, analiz araçları veya kullanıcı takip sistemleri kullanılmamaktadır. Seçtiğiniz açık/koyu tema tercihi yalnızca kendi tarayıcınızın yerel depolamasında saklanır; bize veya üçüncü taraflara gönderilmez.

3. Teknik Veriler

Web sitesi GitHub Pages altyapısında barındırılmaktadır. GitHub, hizmetin sunulması ve güvenliği kapsamında IP adresleri ve teknik erişim kayıtları gibi verileri kendi politikalarına göre işleyebilir.

4. Üçüncü Taraf Hizmetler

GitHub altyapısı dışında şu an için herhangi bir analiz veya reklam hizmeti kullanılmamaktadır. İleride üçüncü taraf hizmetler eklenirse bu bilgilendirme güncellenecektir.

5. İletişim

Gizlilik politikasıyla ilgili sorularınız için web sitesinin sahibiyle iletişime geçebilirsiniz.

6. Güncellemeler

Bu bilgilendirme, web sitesindeki değişikliklere bağlı olarak güncellenebilir.
